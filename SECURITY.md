# Security Policy

## Supported version

Only the latest GitHub Release receives security fixes.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Use GitHub's private vulnerability reporting for this repository and include the affected version, reproduction steps and impact.

MacB uses public macOS APIs and does not run shell command strings. ZIP extraction rejects path traversal, symbolic links, device entries, excessive entry counts and oversized expanded archives. Application removal shows exact candidates and moves approved items to the Trash.
