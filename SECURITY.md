# Security Policy

## Supported version

Only the latest GitHub Release receives security fixes.

## Reporting a vulnerability

Do not open a public issue for a vulnerability. Use GitHub's private vulnerability reporting for this repository and include the affected version, reproduction steps and impact.

MacB does not run shell command strings. ZIP extraction rejects path traversal, symbolic links, device entries, excessive entry counts and oversized expanded archives. Application removal shows reviewed candidates and moves approved items to the Trash.

Most features use documented macOS frameworks. Numbered Mission Control desktop grouping dynamically loads read-only SkyLight symbols, and supported Apple silicon MacBooks may expose an undocumented hinge sensor. Both features fail closed to their public or disabled fallback when the system interface is unavailable; neither weakens SIP or writes to those system services.
